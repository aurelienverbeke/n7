\part{Introduction}

Le \textsc{Minishell} est un shell minimaliste qui permet de lancer des commandes, changer de répertoire courant, afficher le contenu d'un répertoire.

Les commandes peuvent être lancées en arrière-plan et chaînées, et l'utilisateur peut faire des redirections d'entrées / sorties.

\part{Processus}

\noindent
\textbf{Etape 2}

On ajoute \cinline/execvp(commande[0], commande)/. Cela permet de remplacer le code courant par celui de la commande.

On utilise la version \texttt{vp} pour pouvoir transmettre tous les arguments en une seule fois et pour pouvoir utiliser le \texttt{PATH}.

\bigskip
\noindent
\textbf{Etape 3}

Dans le père, on ajoute la directive \cinline/wait()/ pour attendre la termiaison du fils lancé.

\bigskip
\noindent
\textbf{Etape 4}

Dans le père, on remplace \cinline/wait()/ par
\begin{ccode}
if (ligneCommande->backgrounded == NULL) {
	int status;
	if (waitpid(pidFils, &status, 0) == -1) {
		exit(EXIT_FAILURE);
	}
}
\end{ccode}

On attendra alors que l'éxécution des fils en avant-plan se termine.

Il est nécessaire d'effectuer un \cinline/waitpid()/ sur le fils lancé pour ne pas que le traitement du père soit rétabli après la terminaison du fils en arrière-plan.

\part{Signaux}

\noindent
\textbf{Question}

Voir étape 4.

\bigskip
\noindent
\textbf{Etape 5}

On ajoute

\begin{ccode}
actionFilsTermine.sa_handler = handlerFilsTermine;
actionFilsTermine.sa_flags = SA_RESTART;
sigemptyset(&actionFilsTermine.sa_mask);
if (sigaction(SIGCHLD, &actionFilsTermine, NULL) == -1) {
	exit(EXIT_FAILURE);
}
\end{ccode}

\noindent
en début de \cinline/main()/.

La fonction de traitement est

\begin{ccode}
void handlerFilsTermine() {
	fprintf(stderr, "Handler : Le fils a change d'etat\n");
}
\end{ccode}

\bigskip
\noindent
\textbf{Etape 6}

On peut remplacer la fonction de traitement par
\begin{ccode}
void handlerFilsTermine() {
	int status;
	pid_t pid = waitpid(-1, &status, WNOHANG|WUNTRACED|WCONTINUED);

	if (WIFEXITED(status)) {
		fprintf(stderr, "Handler : Fils %d termine avec le code %d\n",
						pid, WEXITSTATUS(status));
	} else if (WIFSTOPPED(status)) {
		fprintf(stderr, "Handler : Fils %d suspendu\n", pid);
	} else if (WIFCONTINUED(status)) {
		fprintf(stderr, "Handler : Fils %d repris\n", pid);
	} else if (WIFSIGNALED(status)) {
		fprintf(stderr, "Handler : Fils %d tue\n", pid);
	}
}
\end{ccode}

\bigskip
\noindent
\textbf{Etape 7}

On remplace le \cinline/waitpid()/ du traitement du père par un simple \cinline/pause()/.



\part{Remarques supplémentaires}

On fait bien attention à ne pas faire de \cinline/printf()/ pour ce qui ne concerne pas les commandes (informations, erreurs...).
Sinon, on risque d'injecter des données dans les canaux \cinline/stdin/ (0) et \cinline/stdout/ (1).
